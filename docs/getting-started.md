# Getting started

{: .note }
Not released yet. Needs a [DAOLib](https://www.nexusmods.com/dragonage/mods/7052) newer than 0.2.0.

## Install

1. Install [DAOLib](https://www.nexusmods.com/dragonage/mods/7052).
2. Extract the zip into the game's folder, so that `bin_ship\daolib\plugins\elgarashaders` is there.

## Mods

Materials from mods work automatically.

## Remove

Delete `bin_ship\daolib\plugins\elgarashaders`.
